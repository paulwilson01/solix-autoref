# Solix Bot Installer (ARM64)

This is a simple one-step installer script to download and run the **Solix Bot** on any Linux or Termux device with an ARM64 CPU.

---

## 📦 What This Script Does

- Creates a folder called `~/solix-bot`
- Downloads the `solix-linux-arm64` binary
- Makes it executable
- Runs the Solix bot immediately

---

## 🧠 Requirements

- A Linux-based system or Termux (Android)
- ARM64 architecture (most modern phones & servers)
- Internet access

---

## 🚀 How to Use

### ✅ Step-by-Step (Copy & Paste This)

```bash
wget https://raw.githubusercontent.com/YOUR_USERNAME/solix-installer/main/solix-install-arm64.sh
chmod +x solix-install-arm64.sh
./solix-install-arm64.sh
